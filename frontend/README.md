# Заклади Тернополя — фронтенд

React + Vite + Tailwind, карта на Leaflet/OpenStreetMap. Збірку я перевірила
(`npm run build` проходить без помилок) — лишається підключити реальний бекенд і задеплоїти.

## Дизайн — коротко

Мінімалістичний, але не типовий "AI-мінімалізм": холодна кам'яно-сіра основа
(не кремова), глибокий смарагдово-тіловий акцент замість терракоти, і золотий
колір лишається виключно для зірок рейтингу — ніде більше не використовується
як прикраса.

Шрифти: **Literata** (редакційний серіф — заголовки, назви закладів, і
курсивом — "особиста нотатка" від LLM у результатах пошуку) + **Golos Text**
(нейтральний гротеск з повною підтримкою кирилиці — весь інтерфейс). Обидва
підключені через Google Fonts у `index.html`.

"Фішка" сторінки — сам пошук: замість звичного списку з фільтрами, результат
подається як "Ось що я знайшла для «твій запит»" з короткою поясненням від
LLM під кожною карткою курсивом, ніби порада знайомого, а не видача пошуковика.

## Локальний запуск

```
npm install
cp .env.example .env.local   # встав туди адресу свого бекенду
npm run dev
```

## Деплой на Vercel

1. Підключи репозиторій на vercel.com (Framework Preset: Vite підхопиться сам)
2. У Project Settings → Environment Variables додай `VITE_API_BASE_URL`
   з адресою задеплоєного бекенду (`https://твій-бекенд.vercel.app`)
3. Деплой

## Структура

```
src/
  App.jsx              — стан застосунку, зв'язує все разом
  api.js                — виклики до бекенду
  components/
    Hero.jsx            — пошуковий рядок (головний елемент сторінки)
    CategoryFilter.jsx  — фільтр-чіпи по категоріях
    VenueGrid.jsx        — сітка карток (і для браузингу, і для результатів пошуку)
    VenueCard.jsx        — картка закладу
    MapView.jsx          — Leaflet-карта з мітками
    VenueDetail.jsx       — деталі закладу + відгуки + форма відгуку
    ReviewForm.jsx        — форма відгуку (ім'я, зірки, коментар, honeypot)
    StarRating.jsx        — зірки рейтингу
```

## Наступний крок

Коли обидва проєкти (бекенд і фронт) задеплоєні і в базі є кілька реальних
закладів — можна пробувати повний цикл: перегляд → пошук запитом → відгук.
